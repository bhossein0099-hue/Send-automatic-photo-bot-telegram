# Telegram Auto Photo Sync (ارسال خودکار عکس به تلگرام)

یک برنامه اندرویدی مدرن با **Jetpack Compose** و **Material Design 3** برای همگام‌سازی و ارسال خودکار و دستی عکس‌های گرفته‌شده با دوربین به بات تلگرام.

## 🚀 ویژگی‌های کلیدی

- **اتصال مستقیم به ربات تلگرام (Telegram Bot API):**
  - فرمت استاندارد `https://api.telegram.org/bot<TOKEN>/sendPhoto`
  - آپلود چندبخشی (`multipart/form-data`) با فیلدهای `chat_id`، فایل تصویر و شرح (caption)
  - فشرده‌سازی خودکار تصاویر بزرگ برای رعایت سقف مجاز تلگرام
  - مخفی‌سازی و امن‌سازی توکن‌ها در لاگ‌ها و گزارش خطاها

- **صف آپلود پایدار (Persistent Queue):**
  - ذخیره‌سازی وضعیت عکس‌ها و تلاش‌های مجدد در پایگاه داده محلی Room
  - ارسال خودکار در پس‌زمینه به کمک Foreground Service و WorkManager

- **امنیت و قفل برنامه (App Lock):**
  - امکان فعال‌سازی پین‌کد (PIN Lock)
  - ذخیره‌سازی توکن و شناسه چت و پین به صورت رمزنگاری‌شده با AES-GCM و `AndroidKeyStore`
  - صفحه‌کلید امن عددی برای باز کردن قفل

- **رابط کاربری مدرن Material 3:**
  - پشتیبانی از تم تاریک و روشن
  - نمایش وضعیت آپلودها، تاریخچه ارسال، گالری انتخابی و تنظیمات کامل
  - انتخاب‌گر مدرن عکس اندروید (`PickVisualMedia`) بدون نیاز به دسترسی‌های خطرناک

## 🛠️ پیش‌نیازها و راه‌اندازی

1. پروژه را در **Android Studio** (نسخه Ladybug / Meerkat یا جدیدتر) باز کنید.
2. تنظیمات پیش‌نیاز:
   - **JDK 17** یا بالاتر
   - **Android SDK:** حداقل نسخه ۲۶ (Android 8.0) و نسخه هدف ۳۵
3. پروژه با Gradle به صورت خودکار Sync خواهد شد:
   ```bash
   gradle assembleDebug
   ```

## 📱 راهنمای استفاده

1. یک ربات تلگرام در [@BotFather](https://t.me/BotFather) ایجاد کرده و **Bot Token** را دریافت کنید.
2. یک پیام به بات خود یا گروه موردنظر بفرستید و **Chat ID** (عددی) را بردارید (مثلاً از طریق [@userinfobot](https://t.me/userinfobot) یا متد `getUpdates`).
3. در تب تنظیمات برنامه، توکن و چت‌آیدی را وارد کرده و دکمه **آزمایش اتصال** را بزنید.
4. در صورت تمایل، قفل برنامه با پین‌کد را از تنظیمات فعال کنید.

## 🔒 امنیت و حریم خصوصی

- هیچ اطلاعات یا کلید محرمانه‌ای در سورس‌کد پروژه ذخیره نشده است.
- اطلاعات حساس (توکن بات، چت‌آیدی و پین) در حافظه امن دستگاه رمزگذاری می‌شوند.
- پروژه شامل فایل استاندارد `.gitignore` برای جلوگیری از کامیت فایل‌های حساس (مانند `debug.keystore`، فایل‌های بیلد و تنظیمات محلی) است.
